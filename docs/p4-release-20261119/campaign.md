# 24日引导、营地与出勤选择

三条路线从标准难度的新周目开始。每一场战术行动来自游戏的“看看下一步怎么做”或脚本明确选择的紧急撤退，每晚经正式存档写入与读取再出发。脚本接受界面所用的教学说明，并通过正式指令安排人员、药品和项目。营地阅读没有代选故事、扣资源或发经验。各路线的时间成本、易读性和趣味仍须由目标玩家记录。

## 实装返修

- 营地读档后日期来自 JSON。原第6晚以后的整数取模会触发脚本错误，后续推荐队列失效。本轮逐晚写盘再读取，并对第6晚的实际推荐设断言。
- 初测中，M02会依次介绍施工、抛索、标记和协作。现在该场围绕诊所回路教学，M03在携带撬棍的人遇到轻障碍时说明工具，M04用桥面施工介绍协作。已学操作保留，可主动查阅当前角色的其他手段。
- 营地学过的常用功能直接打开。三个基础入口和一个近期入口保持在当晚，其他已学功能收进手册。采购每隔至少三晚才主动介绍下一件，且按下场地形、敌人、任务对象、解锁条件与实际可支付价格筛选。玩家仍可随时手动购买。
- 现场支援显示包含当晚在内的剩余有效晚数，已经使用当晚名额后撤下参与按钮。定稿允许自愿在窗口结束后花费一项目、2物资补修，已把此时的按钮写明为公益修复，仅记入社区后记。
- 证据核查从同一条规则取可查记录、项目余额和日期。已选的公开方式不会重复提交。最后一晚若尚未选择路线，夜间总结直接带到可选路线页面，已选择时显示路线名称。
- 战术说明按当前专长等级读取。苏棠5级转交行动点的说明与移动协调各自对应实际模式。绝缘示例匹配涉水机的放电，屏障示例匹配能截断的机器预告；值守过期后撤去未学值守提示。采用既有等级、次数和费用。
- 坐标可能来自鼠标整数，也可能来自 JSON 数字。旧的屏障键会因两种数字拼写出现“看得到盾却能踩上去”的情况。屏障查找兼容老键，新设置的盾使用统一键，移动与专长路径都遵守不能落在屏障格的限制。旧拼写、读盘坐标、重复放盾及可到达格有独立回归。
- 36关简报改为玩家可用的三语说明。M07交代先救维修员再抄编号，M09明确许舟5级携人抛索，S05明确绝缘布也需带回，M24按已选路线的实际目标出勤。其余任务的前置、普通方案、可选成果和终夜都按定稿逐关复核。上一场失败带来的预告碎石也会在简明准备页提示。

## 从首场救援逐按钮走到结局

另有一条简中、1280×720、标准难度、减少动态效果的新周目。创建隔离新存档以后，棋盘和按钮均由 Godot 视口处理鼠标事件，确认窗也经过实际焦点和命中判断。首场逐项点击移动、棋格、稳定、拾起、交付、撤出。之后使用界面上的“看看下一步怎么做”，接受当前现场说明，确认或取消实际预览。营地选择暂缓安排，第2晚在结束总结补读故事说明，第23晚先取消最终路线预览，返回路线页后重新选择，再确认进入终战。

夜间总结仍独占焦点时弹出确认，Godot 每晚都会报告窗口冲突。现有菜单会先让出焦点，已取消的路线选择可回到原页。第20晚状态栏曾把同组两座避难所同时列在“已达成”后，实际只保住了西避难所，东侧仍未完成。状态栏现只显示本周目确实保住的目标。第23晚的预览原来只显示零消耗，现在逐条列出本次所选路线的终战目标。三语、三条合法路线均从同一真实第23晚存档核对过预览与取消。[九组预览内容](../../outputs/p4release-20261119/route-preview-macOS.json)

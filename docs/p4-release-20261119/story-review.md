# 剧情、回看与三语复核

第 2 晚林岚的交班单和第 17 晚已经谈妥的接班表，现在都可以从日志翻页、看全文、核对当时的选择，再回到原日志。原界面翻一句就销毁窗口，丢失了回到原日志的入口。现有窗口就地换页，读全文时单独滚动对话，按钮留在下方。只读来信显示「查看全文」，未能当面协商时展示值班簿，无人物立绘或现场回应。

过去，未选择个人计划的角色也可能说自己已经付款、约定或授权。现在按当前约定区分未建立、未兑现和后续违约。超期计划、缺凭据、缺资金或项目已满的选择会在对话内标明原因，按钮与正式命令共用相同条件。已到期的旧事只留在档案，未结束的战役可以在回到营地后继续符合条件的交谈。两栏布局解决了 720p 大字号下后两个回应滑到首屏下方的问题。

英文重新处理了 54 个人物、关系、生活节点的常规开场、每项选择、回应、标题，另覆盖 24 张社区回访的三种结果与 18 段章节的两种结果。简繁英文都修了混合战果的事实；繁中针对引号、人物口气、影本/復健等用词与关键歧义逐项调整。英文原有把归还玩具写成归还孩子、把求援条钉在居民背上、把电影没看完译成没读完、把隐私边界写成物理封锁区的错误已经改正。三语 UI、36 条简报和人物内部 ID 共享原有数据，冻结设计与配音授权未变。

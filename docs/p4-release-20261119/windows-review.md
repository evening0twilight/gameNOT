# 这份候选怎样实测

候选标识为 p4release-20261119。请完整解压，并让 EXE 与 PCK 保持在同一目录。build-receipt.json 给出两者的 SHA256。旧包上的“能玩但质量差”保留为旧包反馈，本次单独记录。

## Windows 参考机

1. 在 Windows 11 x64、8 GB 内存的机器设置 1920×1080，重启后首先用 Record-Windows-Session.cmd 启动一次正常游戏。先运行其他检查会预热资源。记录显示器刷新率、首次可操作时间。每分钟的进程记录、启动时间与游戏诊断保存在这一次的目录中。[采集说明](reference-session.md)
2. 同一个进程持续玩至少两小时，期间交替进行战斗、营地、剧情和读档；在不同章节留出稳定棋盘采样段。结束时留足两小时采样跨度。记录画面停顿。用高帧率视频记录实际按键/鼠标动作到可见反馈，注明采样帧率与测量误差。
3. 另行双击 Run-Windows-Checks.cmd，记录三场隔离任务、读档与键鼠/字号布局冒烟结果。实际正常周目还要检查取消/确认、暂停/跳过、音效与音乐独立调节、手动存档/重开/备份恢复。
4. 提供本候选标识、测试时间、实测机器、设备采样目录和失败步骤。涉及存档问题时保留该次测试档。测试结果需能和这次运行的 EXE/PCK 哈希对应。

## 新人观察

组织至少五名未看过方案的目标玩家。交给每人一份新周目和 README.txt 的启动说明。FIELD-GUIDE.txt 含救援步骤，可在首场观察完成后提供。观察员记录发生了什么和在哪一格、哪一个界面卡住。首场完成前避免口头教学；确实需要提示时把位置、原话和耗时记下。不要在测试前把攻略或答题要点交给参与者。

| 时点 | 观察员记录 |
| --- | --- |
| M01结束 | 请玩家用自己的话说明任务目标、机器预告、怎样撤出及另一种解法。记录哪几项独立说清，是否需要帮助。至少4/5人需独立说清四项。 |
| 一章结束 | 分别记录5人的一次“练或不练”和一次“换或不换”的具体理由、角色、任务和代价。 |
| 连续24日 | 留5份完整记录。覆盖以主线为主、积极支线、固定喜好队。按日记战斗、阅读、夜间管理分钟数，是否被迫恢复/等待、资源是否卡关、哪些操作一再重复。 |
| 图像、声音与结局 | 标记96px辨人误认、文字或按钮被遮住的位置，危险提示是否只靠颜色。有无听不清的反馈、循环疲劳、切换突兀。记录与实际救援、知情、出勤或离队事实冲突的台词。 |

可让同五位玩家从首场玩到结局，沿用匿名编号。表格一行对应一次观察；夜间耗时逐晚填。由观察员记录每类结果和原话，保留个体差异。整局的存档丢失、无法操作、错误永久离队、与基本事实冲突的剧情和误导关键决策的解释，发现一项就保留存档并停止发行判断。

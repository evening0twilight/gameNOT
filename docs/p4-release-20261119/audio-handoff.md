# 六个音乐场景的本轮改动

0.18 的标题与营地、普通任务、紧急任务、人物日常、沉重事件、结局现使用六首阿里云百炼 Qwen 器乐录音的离线剪辑。24 个短音效沿用工程原有合成文件。运行时只读游戏资源。六个场景继续使用各自的声部、交叉淡化及独立音乐音量。玩家听完一段人物故事再回到营地，底乐从离开时的乐句继续。游戏重新启动后音乐位置重新开始。

| 场景 | 成品处理与辨识线索 | 单次引子 / 之后循环 |
| --- | --- | --- |
| 标题、营地 | 11 月 17 日试作加入鼓点后明显改变安静营地的质感。这一版改录柔音钢琴独奏，让浏览安排时保有静处。 | 10.96 / 25.50 秒 |
| 普通任务 | 长弓弦乐在前，给移动、稳定和目标提示留出空间。 | 7.38 / 27.46 秒 |
| 紧急任务 | 拨弦重复音型和更密的脉冲提示压力。辅助听辨仍能感觉乐句反复。 | 9.82 / 32.26 秒 |
| 人物日常 | 拨弦琶音和连贯弦乐。将第一乐句的衰减与下一乐句的起音相接，去掉生成素材中间一次停顿再起的断口。 | 11.92 / 23.82 秒 |
| 沉重事件 | 删除原录音尾部的停顿与短促重启，将音区放低、每个弓段延长至原来 1.4 倍。辅助听辨在返修后辨出了低沉缓慢的弦乐。 | 2.49 / 35.48 秒 |
| 结局 | 低弦与钢琴缓慢应答，保留落句的呼吸和较大的动态。 | 11.98 / 28.56 秒 |

**试听。** 完整串听约 5 分钟，依上表顺序，每段穿过一次循环点。另一个约 22 秒的诊断录音取自 Godot 实际主输出，在默认音乐/效果音量下依次叠加确认、脚步、伤势、翻页、取消和结局提示。它使用脚本定位到每首末段。两个 MP3 统一提高 6 dB 方便试听，时间点和文件指纹见 audio-audition.json。[六首音乐](../../outputs/p4release-20261119-audio-score.mp3) · [Godot 混音](../../outputs/p4release-20261119-audio-mix.mp3)

**来源。** 六份成品使用本项目自行撰写的场景指令。通过已配置业务空间的百炼模型推理 API 调用 qwen-audio-3.1-tts-next，未上传第三方音乐或人声样本。登记对应正式 API 的百炼服务协议；体验广场是另一种入口。协议第 7.5 至 7.7 条说明符合前提的合成内容权利、权利判断责任及相似输出问题。此记录可核对来源和适用条款，未取得专属权利或相似曲目鉴定。提示、服务返回的 usage、源 WAV 指纹、连接失败与同一结果的下载恢复、辅助听辨均见 audio-model-review.json。没有按断连次数推计额外用量或金额。[百炼服务协议](https://terms.alicdn.com/legal-agreement/terms/common_platform_service/20230728213935489/20230728213935489.html) · [服务文档](https://help.aliyun.com/zh/model-studio/audio-generation)

**制作与验证。** 六份原始生成音频的无损 FLAC 保存在仓库 outputs/p4release-20261119/audio-sources/。固定取段、重采样、重叠淡化和按场景的响度处理见 tools/master_release_score.py。紧急任务 127 个、结局 1 个源采样触及满幅，制作时从相邻波形估计边缘，无法恢复录音之前的精确波形。成品响度为 −29.0 至 −26.5 LUFS，最高真实峰值 −11.1 dBTP。六份归档源重新输出的 WAV 哈希全部与生产文件一致。Godot 从 WAV 读取各自的采样帧回环点，同一首曲子的引子只播放一次。

在本机 Godot 4.7.2 的 Dummy 驱动中，六个播放器均越过各自的回环点并返回正确位置，取得非静音的主混音采样。原 24 个短音全部可加载，音量/静音、长剧情后续播、实际新局首场行动、暂停、结局等专项共 81 项通过。独立试导出的 PCK 里能播放六首新曲、读取 24 个短音，13 个旧配乐资源已从导出清单排除，仓库仍保留历史原件。本轮最终 ZIP 的核验以该包单独的收据为准。

辅助听辨输入为未提供场景名的音频对，包含完整剪辑和回环后的 12 秒。真人在游戏中长时聆听、阅读时是否分心、是否能辨别战术提示以及对音乐与角色的喜好仍待实测。此处没有 Windows 音频设备或真人审美验收记录。

本机复核命令如下。外置脚本对最终 PCK 运行时，在输出 JSON 后加入 `--packaged`。

```sh
python3 tools/review_audio_nov13.py
"$GODOT" --headless --path game --script res://tests/p4_audio_nov13.gd -- "$PWD/outputs/baseline018-linked-day24.json"
"$GODOT" --headless --audio-driver Dummy --path game --script res://tests/release_score_review.gd -- "$PWD/docs/p4-release-20261119/audio-runtime.json"
```

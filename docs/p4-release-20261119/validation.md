最终隐藏 GPU 实跑得到 29 张工作区截图、103 项断言。独立的可见周目记录了 2,041 次界面输入及真实结局存档；首战之后采用了界面提供的行动建议。第23晚另测三语×三条路线的确认内容和取消回退。96 节点的 3,231 个三语页面实例与 288 项图形界面检查分开统计。

本次统一全量完成 48 组，绑定 499 个生产文件。最终源码在 Apple M3 的 1920×1080 隐藏 GPU 视口从第23晚存档进入 M24。稳定 30.0 秒、3570 帧，P95 14.88 ms，99.69% 的间隔不超过 16.7 ms。末关12次合成预览到强制绘制 P95 18.63 ms。三个独立进程首次确认出勤到引擎画完首帧分别为 62.9、54.5、73.9 ms（1280×720）。这些值描述开发机的引擎路径，实屏与参考机指标仍须 Windows 原生测量。

统一入口为 python3 tools/check_product018.py --full --jobs 3 --report-prefix p4release-20261119 和 python3 tools/build_windows_product018.py --candidate p4release-20261119 --review-dir docs/p4-release-20261119。报告中的源码摘要包含音频导入参数。另可用 python3 tools/review_release_slots.py 复跑两进程真实恢复，用 python3 -m unittest discover -s tools -p test_history_validation.py 复跑12项历史清单边界。Windows 原生和最终真人验收标记仍为 false。

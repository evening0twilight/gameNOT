# p4languages-20261117 候选说明

这份开发候选新增简体中文、繁體中文、English；仍不是正式发行版本。

启动页或右上角「设置与存档」→「语言 / Language」切换。英文中为 Settings & Save → Language。三种语言使用同一存档；语言与字号为独立偏好，重新启动保留。原存档不重置进度、不重发角色或奖励。游戏没有运行时模型/API依赖。

本轮调整了英文教学、姓名和目标标签、动态说明、剧情说话人，以及三种语言在720p三种字号下的选项布局。仍沿用第一场逐步学习、第二场之后按场景介绍新操作的规则。Qwen营地音频只作外部试听，本包正式配乐仍沿用现有音源。

查看PRODUCT-REVIEW.md与validation.txt了解实际覆盖范围。Windows x64导出与本机加载不代表Windows原生测试，更不代表已通过品质验收。后续问题请按本候选名、语言、任务、界面和操作记录；不需要远程连接。

English: Choose Settings & Save → Language. Language and text-size preferences are separate from campaign saves. This is a development candidate, not a final release.
繁體中文：在「設定與存檔」→「語言 / Language」切換。語言與字號不影響戰役存檔；本候選尚未通過最終品質驗收。

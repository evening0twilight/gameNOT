# 第一场救援、第一晚与关键剧情返修（2026-11-17）

这轮直接落实用户提出的逐步教学。此前 Windows“能玩但品质差”的结论没有被检查通过覆盖；当前仍是 P4 产品返修候选，不能发布为正式完成版。配乐按要求暂停。本轮没有新生成音乐，也没有迁移平台。

## 玩家现在会经历什么

1. 新周目先看到渡轮与“两位居民仍在船上”的目的，直接出发。默认不连弹三个角色介绍，不把装备、关系、专长和后勤全部摆到开局。完整准备仍可主动展开。
2. 进入现场自动选中移动并亮出可走格，动作区只有移动。常驻卡说明为什么要移动、如何点地图、如何看预览并确认。之后学习危险预告、换人和回合，再逐个出现稳定、拾起、交付、离场。已经使用的功能保留，提示随真实局面重算，允许自己选路线。
3. 取消预览不完成教学、不扣 AP；阅读危险提示不推进回合；撤销会恢复对应学习进度。跳过是持久偏好，撤销不会把教学强行打开。旧周目不自动重播新教程。
4. 第一场结算先呈现救回的人数、实际结果、经验和资源；主要入口是回营地。社区记录、公开方式和关系事实可另行查看，完整结算仍可展开。失败或部分完成不伪装成完美救援。
5. 第一晚先看到三位伙伴、疲劳和睡眠后的数值，按需选择恢复/培养或短谈。剩余项目/谈话数随真实消耗更新，明确可以不花完。项目选择仍经过原来的费用预览与确认，结束夜晚仍走正式复核。
6. 第一晚的记录引用本次 M01 的实际社区结果，不提前解锁第 2 日人物剧情。随后林岚关键场景使用更大的场景和人物、底部对白、暗化背景；做决定时压缩舞台，直接露出两项选择和延期。选择后接续新回应，不从开头重放。林岚/许舟/苏棠第一幕补充当前场景动作，只用于当面呈现，不塞进来信或休养版本。

## 实际修到的卡点

- 完成目标后两个出口被队员占着，远处队员提示“找不到路”。现在先提示能离开的出口队员离场；出口队员 AP 用尽时先提示下一轮，不再反复让远处队员挤进去。
- 明确出发后的动作选择复位为移动，即使此前选择过其他操作也能直接看到可走范围。
- 第一晚长按钮窄到分行、正文被推下去；已明确按钮宽度并压缩次要信息。
- 对话选择被大立绘挤到屏幕外；决定页采用紧凑舞台，让关键选择在 720p 默认字号同屏可见。
- 跳过教程后撤销会重新开启；现将“跳过偏好”与“随行动撤销的学习进度”区分。
- 教学里的“确认执行/离场”与实际按钮“确认行动/撤出”不一致，已逐字对齐；查看完整结算独立打开窗口，不再关闭后续教学。
- 教学政策修订改变内容指纹可能拒绝旧档；只接受这次准确的前一版指纹，仍验证校验和、版本与完整状态，不泛化放行未知内容。

## 新手角色与获取顺序

保留林岚、许舟、苏棠作为长期可培养的新手班组；三人开局已有，第一晚明确角色用途，**不把已持有角色包装成重复赠送**。不额外赠送后期人物或专长等级。当前人物是各有用途的固定队员，没有凭空新增稀有度、抽卡或战力榜。

| 人物 | 首次可用时点 | 入队经验 / 等级 | 为什么这样安排 |
| --- | --- | --- | --- |
| 林岚 | 新周目 | 0 / Lv1 | 远距稳伤帮助救援；不免费治疗、复活或跳过搬运 |
| 许舟 | 新周目 | 0 / Lv1 | 跨单格障碍提供机动；初期不能带着伤员跨越 |
| 苏棠 | 新周目 | 0 / Lv1 | 标记辅助下一次普通攻击；仍需花 AP 和队友配合，不是直接爆发伤害 |
| 陈砚 | M04 结算后 | 0 / Lv1 | 第一章后段引入机器中断与装置保护的理解 |
| 叶禾 | M07 结算后 | 12 / Lv2 | 永久隔离需靠近、2 AP、限次；在玩家认识停机后出现 |
| 贺鸣 | M10 结算后 | 12 / Lv2 | 护罩引入位置和时机管理；搬运强化仍需 Lv3 |

| 江朔 | M16 结算后 | 28 / Lv3 | 接力/补给依赖队友站位、接收条件与药剂，后段再扩展组合 |

Lv5 需要 72 经验，Lv6 需要 100；没有新人直接获得。新成员的章节经验底线防止后加入者完全落后，不会达到顶级强化。每章课程次数、两项目夜间预算、费用与疲劳仍生效，不靠无限训练把新手抬满。获取在真实主线结算触发，失败不永久错过固定队员；未结算下一场不能提前加入。本轮不修改获取日或角色数值。

证据：本轮新局路径先证明初始三人、不可提前出战/训练的限制；既有八条真实 24 日重点培养路线在本轮全量检查中重跑。这些重点培养路径中，初始三人到 Lv5 为第10日，陈砚14日、叶禾15日、贺鸣18日、莫遥/江朔20日；这是具体路线的结果，不是最快升级证明。它们支持入队和成长规则一致，不证明所有人物强度已经达到真人平衡标准。

## 权威数据和旧证据

用户这次明确要求“功能键一个一个教、一开始只出现一个”，与旧 tutorial_policy 中默认全部开放的展示要求冲突。因此仅修订 experience.tutorial_policy 的 schedule / not_railroad / automatic_budget 三个字段，并同步生成视图；没有修改关卡、获取、数值、对白、选择或收益。精确授权、前后哈希见 tutorial-amendment.json。旧 baseline 原字节与旧体验投影保存在同目录 before-*，旧受保护哈希清单不改。

历史校验逐字验证旧 baseline 档案、核对新版本准确哈希，并比较 JSON，若三项教学字段之外有变化仍报错。原 287 项中 243 项在原路径原字节核验，1 项旧 baseline 在档案路径核验，43 项按既有清理记录退休；没有把不存在的路径说成通过。

## 仍未达到的品质目标

- 战术地图的细节与角色/机器小尺寸辨识仍不够统一，本轮主要改善第一段的进入、信息层级和操作节奏，不能称全套美术重制完成。
- 第 2 场起仍进入完整工作区，后续专长、协作、装备系统的逐项学习需要继续扩展；本轮分步教学覆盖第一场与第一晚。
- 本轮重点打磨三位初始人物第一幕演出，没有声称重写四章剧情或完成人物吸引力验收。
- 没有本候选 Windows 原生、目标硬件性能或新人盲玩证据；脚本跟随提示不是真人学会操作。没有把这些缺口作为停止修复的理由。

资料与采纳结论
1. Godot 4.7 Project organization
https://docs.godotengine.org/en/4.7/tutorials/best_practices/project_organization.html
采用：小写文件路径、明确大小写、文档目录.gdignore、插件集中addons管理。
调整：纯domain/app/infrastructure仍按责任分层；具体界面场景的私有脚本/纹理可以在同一功能目录就近存放，
共享资产才进统一assets，避免为目录整齐让每次改UI都跨很多目录。当前不批量搬动已有文件。

2. Godot Scene organization / GDScript style guide
https://docs.godotengine.org/en/stable/tutorials/best_practices/scene_organization.html
https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/gdscript_styleguide.html
采用：场景职责单一、从外部注入依赖、减少跨层节点路径、遵循官方命名与声明顺序。
UI子场景用信号报告意图，由协调层连线；domain仍只返回数据，不借信号传播隐式规则事务。
不将所有状态塞入Autoload，不把同一状态分别存在场景、单例、存档模块三处。

3. GDQuest作者指南与信号实践
https://gdquest.gitbook.io/gdquests-guidelines/godot-gdscript-guidelines
https://www.gdquest.com/tutorial/godot/best-practices/signals/
采用：公共接口类型明确、保持可读性、系统交界处清晰、控制信号连接复杂度。
限制：页面部分示例含Godot 3语法，只借鉴原则；正式代码遵守锁定Godot 4.7.2实际解析结果。
不复制旧yield、旧export或字符串connect写法；不把作者旧机器的性能数字当本项目承诺。

4. Godot官方demo仓库
https://github.com/godotengine/godot-demo-projects

仅在需要具体GUI、加载或输入实现时选匹配稳定分支的单个例子，保留许可和来源。
本次未导入demo，也未对其全部源码作审计；不另建可丢弃游戏。

开发环境实测与准备建议
当前主机Apple M3 / 16GiB统一内存，macOS26.5.2；已有Godot4.7.2和Python3.14.7，当前检查运行正常。
本次瞬时观测：swap约4538MiB，压缩页占用约6.5–6.9GiB，系统压力值2；两秒增量采样未见新增swapout。
这说明已有压缩/换页占用，不能只据swap存量断言此刻持续卡顿或项目必须升级内存。
磁盘df报告可用约26GiB。建议先为开发盘留50GiB以上余量（工程工作建议，不是游戏最低磁盘配置）。
16GiB可继续本项目常规编辑/测试；少同时运行大型素材工具、多份编辑器或本地大模型。
本项目不需要本地AI模型、Unity、Unreal、Docker或Visual Studio/.NET。
Windows测试者运行导出包无需安装Godot/Python；只需Windows11 x64、可用驱动、键鼠与可写入用户目录。
如果要在Windows改工程/运行源码检查，才准备同版本Godot、Python和Git。
不自动关闭用户应用，不清理仓库之外的个人文件，不要求购置新电脑。

Windows硬件与兼容性计划
用户报告：RTX5060Ti 8GB显存、16GB系统内存、约1TB存储；CPU为AMD Ryzen 5 5600，SSD；显示分辨率待补。
已写入windows-test-record.json；是用户提供的信息，尚未实机核验。
此电脑可定位为主流中档独显测试机；对本项目2D规模，显卡预期有余量，但没有帧率实测。
存储总容量不代表可用空间或读盘速度；CPU会影响规则/加载/UI，不能只记GPU。
显存8GB与0.18要求的8GB系统内存参考机是两回事，当前16GB机器不能直接完成低内存验收。

计划矩阵（测试覆盖建议，不是新增最低配置承诺，不要求现在购置）：
A 主机：用户5060Ti/16GB，功能、1080p/显示缩放、保存恢复、完整周目。
B 常见旧代独显：借用/试玩者RTX3060或同档30系、RTX4060或同档40系；分别记录完整型号/CPU/驱动。
C 低端：8GB系统内存、具备Compatibility所需OpenGL支持的旧独显或核显机器，验证R07与内存余量。
D 驱动差异：至少补AMD或Intel设备样本；不能只有NVIDIA的三代显卡就声称跨厂商兼容。
没有合适C/D机器时保留“未验证”，可后续借用/招募测试，不先采购。
不同代的低端卡和高端卡不可仅按30/40/50数字排序；降低分辨率或限帧也不能模拟旧显卡驱动和低系统内存。
R07原标准不变：8GB系统参考机，1080p稳定场景95%帧<=16.7ms、冷启动<=10秒、输入反馈<=100ms、
2小时无持续内存增长。CPU/GPU/内存/驱动/磁盘/分辨率/构建hash必须随测量记录。
对8×8的2D回合制，避免为少量实体引入高GPU需求是工程目标；最低配置须等正式代表场景实测后公布。

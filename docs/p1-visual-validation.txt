2026-11-05 / 同一 game 正式工程 / Godot 4.7.2 Compatibility

可玩范围
M01战斗→结算→营地→存读档→M02；首发三人的专长、关系、双人协作、战术撤销保留。
视觉层不写战役规则。资源离线随包交付，游戏运行时不调用生成式AI。

本轮实装
1. 林岚、许舟、苏棠的半写实立绘与职业棋子；临时支援员使用独立的黄衣救援外形。
2. 渡轮钢板/周围海水/栏杆、诊所地砖；人物、伤员担架、维护机器、开关、电源和文件图像。
3. 营地港口救援站插画、三人肖像卡片、关系信任条；训练/治疗/短谈等继续调用正式命令。
4. 可达格取自Session预览；悬停显示目标名称和规则一致的路线；实际移动沿路线过渡，
   行动/受击有短暂光环反馈，水面及机器预告缓慢变化。动画仅展示已成功保存的动作。
5. 保留中文文本目录、伪本地化压力模式、16/20/24字号；图片不包含按钮或剧情文案。

## 自动检查与性能

- 同目录双击 Run-Windows-Checks.cmd，运行隔离存档自动检查。它只覆盖明确列出的自动场景，不等于人工体验通过。
- 正常游戏的设置/帮助中可导出本机诊断。记录Windows版本、CPU、GPU、内存和分辨率；1080p稳定棋盘目标95%帧≤16.7ms。
- 冷启动另用秒表，从启动程序到可操作（目标≤10秒）；诊断中的引擎首帧时间不能替代该值。
- 输入反馈要观察真实键鼠到画面，目标≤100ms；自动预览计时不等于显示端延迟。
- 连续2小时实际游玩，保留开始/中途/结束诊断，并用任务管理器每15分钟记录进程内存。Godot静态分配量不是进程驻留内存。缺少这些记录时保留待验收。

- H01：至少5名新人中4名能在M01解释目标、威胁预告、撤离和一种替代办法，记卡住的界面与动作。
- H02：至少5名玩过一章者解释一次培养/不培养与换人/留队的具体理由。不能用脚本技能调用数代替。

- 听感：主菜单/营地、两档任务强度、日常、沉重事件、结局分别听；独立音乐/音效滑块与静音。记录刺耳、突变、听不清反馈、循环疲劳的具体场景。

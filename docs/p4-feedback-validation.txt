夜潮事务所：P4 交互反馈返工版（2026-11-06）

状态：P4 尚未获产品验收通过。本轮针对用户指出的玩法说明、引导、难度呈现、人物动作与声音反馈不足进行修改。

本轮实现
1. 首次进入的四页玩法介绍；现场「怎么玩」可重看，F1 保留完整帮助。介绍任务目标、行动点、预览确认、回合推进、救援五步和危险预告。
2. 地图下方持续的下一步提示：当前队员无行动点、靠近、稳定、拾起、搬回、交付、施工前置、已启动任务、撤离。金框标出建议目标，按钮只切换行动，不代替玩家执行。既有一次性提示记录兼容保留。
3. 放松/标准/严峻改为独立可选择的说明卡；显示实际任务回合数、伤害变化和永久医疗离队后果。数值规则没有在本轮重新平衡，不能据此声称难度曲线已完善。
4. 八位主角色使用新生成的透明动作图集：四个步态采样（两个主要交替姿态）、准备和伸手/出力姿态；运行时组合路径转向、身体起伏、前倾、推移、受击闪烁与抖动、倒地、离场淡出、伤员搬运、施工与结果文字。
5. 机器回合顺序播放已有预告范围与动作，实际生命差值集中显示；不会把总伤害捏造为某一台机器的独立命中。
6. 脚步、撞击、推移、急救、拾起、工具、交付、受击新增原创合成音效。音频和画面使用同一播放时钟，多个音效可重叠。音乐/音效与静音设置继续有效。
7. 行动仍先由原规则与原子存档提交一次，再播放反馈。播放期间不能重复提交；空格/Esc/跳过按钮只结束表现。最后离场的动画播完再进入结算。旧 P4 存档不需要新 schema。

验证边界
- 反馈测试验证实际动作帧、透明背景、逐格路径、拐角朝向、声音时间点、预览无写入、重复输入防护、跳过不改变状态/存档、撤销、救援步骤、机器回合、自动结束和最后离场。
- 原规则、连续周目、三难度×两天气、界面尺寸/伪本地化回归由当前构建日志记录；具体数量以同名 JSON 报告为准。
- 外接屏截图与录屏来自 macOS 游戏运行；录屏采用隔离位置与合法命令示例，不是自然通关或真人试玩证据。
- Windows x64 导出结构与资源包启动可在本机检查；没有声称执行过新包的 Windows 原生测试。
- 现有素材提供基础步态和交互姿态，不是完整八方向动作库；身体朝向为镜像/轻微倾斜，没有新增翻滚机制。声音听感、动作品质与辨识度仍需实际体验。
- 玩家能否独立理解任务、操作是否顺手、难度是否有趣，均不能由自动测试推出；P4 不因此宣告完成。
